# Bojo — дизайн-принципы (v0.1)

Продуктовая идея экрана: **«с кем и где поиграть сегодня»** за один взгляд. Всё, что не помогает решить «иду / не иду», убираем на второй план.

## Характер
- Чисто, много воздуха, крупные фото площадок, мягкие скругления.
- **Один яркий акцент — «лайм теннисного мяча»** (`#C8F031`). Используется только для главного действия на экране, свободных мест и активного состояния. Никаких молний, красно-чёрных сочетаний, «агрессивного» курсива, градиентов «энергии».
- Нейтральная палитра чуть тёплая (бумага, графит), чтобы фото площадок были главным цветом.

## Цвет (токены)
| токен | light | dark | назначение |
|---|---|---|---|
| `bg` | `#F7F7F4` | `#0E0F0D` | фон экрана |
| `surface` | `#FFFFFF` | `#181A17` | карточки, листы |
| `surfaceAlt` | `#EFEFEA` | `#222420` | чипы, поля ввода |
| `border` | `#E2E2DC` | `#2E312C` | разделители (hairline) |
| `text` | `#121411` | `#F2F3EE` | основной текст |
| `textMuted` | `#5B6058` | `#A3A89E` | вторичный текст (≥ 4.5:1 на `bg`/`surface`) |
| `accent` | `#C8F031` | `#C8F031` | заливка главной кнопки, бейдж «свободно» |
| `onAccent` | `#121411` | `#121411` | текст/иконки на акценте |
| `accentText` | `#3E6A00` | `#C8F031` | акцент как цвет текста/иконки (контраст ≥ 4.5:1) |
| `danger` | `#B3261E` | `#F2B8B5` | ошибки, «не пришёл», жалоба |
| `success` | `#1E7A3A` | `#8FD9A8` | подтверждения |
| `overlay` | `rgba(18,20,17,0.5)` | `rgba(0,0,0,0.6)` | подложки модалок |

Правило: акцент **никогда** не используется как цвет текста на светлом фоне — только `accentText`.

## Типографика
Одно семейство — **Manrope** (кириллица + польская латиница), через `@expo-google-fonts/manrope`; системный шрифт — фоллбэк до загрузки.
Шкала: `display 32/38 800`, `title 22/28 700`, `headline 17/22 700`, `body 15/22 500`, `label 13/18 600`, `caption 12/16 500`. Поддержка Dynamic Type: `allowFontScaling` включено, ограничение `maxFontSizeMultiplier` 1.6 на плотных элементах (чипы, таб-бар).

## Сетка и формы
- Отступы — шкала 4: `4, 8, 12, 16, 20, 24, 32, 40`. Боковой отступ экрана 20.
- Скругления: `sm 8`, `md 14`, `lg 20`, `pill 999`. Карточки — `lg`, кнопки — `pill`.
- Тени минимальные (только у плавающих элементов поверх карты); в тёмной теме — без теней, через `surface` светлее фона.

## Доступность
- Тап-зоны ≥ 44×44 pt (iOS) / 48×48 dp (Android); `hitSlop` у мелких иконок.
- Контраст текста ≥ 4.5:1, крупного/иконок ≥ 3:1 в обеих темах.
- У каждой интерактивной иконки `accessibilityLabel`; у карточек — сводный label («Футбол 5×5, сегодня в 18:00, Pole Mokotowskie, свободно 3 места из 10»).
- Не передавать смысл только цветом: «свободно 3» — число + текст, уровень — текст + точки.
- Уважать `reduceMotion`.

## Пиктограммы видов спорта
Собственный набор (react-native-svg): сетка 24×24, живая область 20×20, обводка 1.75, скруглённые концы и углы, без заливок (заливка допустима только в активном состоянии пина). Один визуальный приём на иконку (мяч с характерным швом, ракетка, волна, турник, кроссовок/дорожка). Набор: football, tennis, basketball, volleyball, beach_volleyball, table_tennis, padel, swimming, workout, running, multi.
UI-иконки (стрелки, чат, фильтр…) — Feather из `@expo/vector-icons` (та же логика обводки, без лишних зависимостей), чтобы стиль совпадал.

## Ключевые компоненты
- **EventCard** — читается без открытия: пиктограмма спорта + название, **время крупно** («Сегодня 18:00»), площадка + расстояние, стек аватаров идущих (до 4 + «+N»), бейдж свободных мест на акценте («ещё 3»), уровень. Кнопка «Иду» прямо на карточке.
- **VenueCard / VenueSheet** — фото во всю ширину (16:9), атрибуты чипами: покрытие, освещение, платно/бесплатно, часы; ниже «Ближайшие события». Плашка «© OpenStreetMap contributors» у данных OSM.
- **Map** — главный экран: карта на весь экран, сверху чипы видов спорта (горизонтальный скролл), снизу выдвижной лист (bottom sheet) со списком площадок/событий в видимой области. Пины: круг 36pt с пиктограммой; акцентное кольцо, если на площадке есть событие сегодня.
- **PersonCard** (свайп) — фото/аватар, имя, район (не точная геопозиция!), «~2 км», виды спорта с уровнем, пересечение графика («совпадаете: вт, чт вечер»), надёжность.

## Тон текста
Коротко, по-дружески, без восклицаний и спортивного пафоса. «Иду», «Ещё 3 места», «Сегодня 18:00», «Никого рядом — создайте событие первым».
