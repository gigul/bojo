## Не вошло в MVP (бэклог)
- Импорт активностей Strava / Apple Health / Google Fit; маршруты бега на карте (модуль 4 — заготовка: схема + экран темпа/дистанции + групповые пробежки как события)
- Верификация профиля — только ручная модератором (`set_user_verified`), без автоматического флоу
- Модераторский интерфейс (очередь жалоб и правок площадок) — пока только RPC
- CAPTCHA, свой SMTP, квоты Storage, удаление объекта при скрытии фото (см. README → Безопасность)
- Запуск на реальных устройствах (Expo Go/EAS), push на устройстве, VoiceOver/TalkBack
- Фото площадок: в OSM их почти нет — только пользовательские загрузки
